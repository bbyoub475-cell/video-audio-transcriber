# 视频音频转文字工具（Mac 专用）

把视频或录音里的话自动变成文字。完全在你自己的电脑上运行，不用联网，不花钱。

> [!CAUTION]
> ## ⚠️ 只能用在苹果芯片的 Mac 上（M1、M2、M3、M4 等）
> Windows 电脑和老款 Intel Mac 都不能用！

---

## 项目介绍

这个工具基于 OpenAI 开源的语音识别模型 **Whisper**，用的是 whisper.cpp 这个能在苹果芯片 Mac 上高效运行的版本。模型和程序都在你自己的电脑上运行，视频和录音不会上传到任何地方。

致谢与来源：

- OpenAI Whisper：https://github.com/openai/whisper
- whisper.cpp：https://github.com/ggml-org/whisper.cpp
- 模型文件来自 Hugging Face 上的 ggerganov/whisper.cpp
- 静音检测使用 Silero VAD

本项目只是把它们打包成了方便小白使用的一键工具，识别能力归功于原作者。

---

## 使用限制（先看这里）

- 需要一定的电脑空间：工具加一个模型约 2GB，两个模型都下载总共约 4.5GB，请先确认硬盘有空位
- 两个模型各有特点：「性价比」模式速度快、占用小；「最高准确」模式更精准，但模型很大，内存小的 Mac 可能会很慢或卡住。内存小就选性价比模式
- 转换速度：性价比模式约 1 小时的内容转 3 分钟；最高准确模式约 9 分钟
- 识别不是百分之百准确，个别词可能听错，重要内容请自己再核对一遍
- 说话（会议、课程、访谈）识别得最好；**唱歌、带背景音乐的内容准确率会明显下降**，只能当参考
- 转换时电脑会比较吃力，风扇可能会响，属于正常现象
- **首次使用可能会出现小 bug（比如卡住、报错、没有输出）。遇到时先把运行窗口关掉，重新启动一次再运行，一般就正常了。如果还是不行，多重启几次再试**
- 切换模式后，输入文件夹里以前转过的文件会重新转一遍，并覆盖旧结果。想留旧结果，先把它从输出文件夹里挪走

## 第一步：下载工具

1. 在本页面找到文件 **视频音频转文字.zip**，点它
2. 点右边的下载按钮（向下的箭头），等它下载完
3. 去「下载」文件夹，双击这个 zip，会自动解压出一个叫 **视频音频转文字** 的文件夹
4. 把这个文件夹拖到桌面，方便找

## 第二步：下载模型（必须做，不然用不了）

模型是工具的「大脑」，文件很大，所以没法放在这里，需要你自己下载。
点下面的链接，浏览器会自动开始下载，等它下完：

**① 静音检测（必须下载）：**

https://huggingface.co/ggml-org/whisper-vad/resolve/main/ggml-silero-v5.1.2.bin

**② 主模型（下面两个至少选一个，也可以两个都下，两个是同一级别的推荐）：**

- 【性价比】速度快、占用小，适合大多数人：
  https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3-turbo.bin
- 【最高准确】更精准，但文件很大（约 3GB）、速度慢一些，内存大的 Mac 推荐：
  https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3.bin

> 怎么选：想快、电脑内存小，选「性价比」；想要尽量精准、电脑内存大，选「最高准确」；拿不准就两个都下，之后可以随时切换。

## 第三步：把模型放到正确的位置

1. 打开桌面上的 **视频音频转文字** 文件夹
2. 里面有一个叫 **app** 的文件夹，双击打开
3. 在 app 里面找到 **models** 文件夹，双击打开（如果没有 models，就自己新建一个，名字必须是 models，全小写）
4. 打开「下载」文件夹，把刚才下载的 .bin 文件**拖进 models 文件夹**

放好以后，models 文件夹里应该有：

- ggml-silero-v5.1.2.bin（必须有）
- ggml-large-v3-turbo.bin（下载了性价比模型才有）
- ggml-large-v3.bin（下载了最高准确模型才有）

> [!CAUTION]
> 文件名一个字都不能改！

## 第四步：开始使用

1. 把要转文字的视频或音频文件，放进文件夹里的 **输入** 文件夹
2. 双击 **开始转换.command**
3. 等它跑完（窗口里会显示进度）
4. 结果在 **输出** 文件夹里，是文字文件和字幕文件

> 💡 首次使用如果出现卡住、报错或没有输出，先关掉窗口，重新启动再运行一次，多重启几次通常就能正常用。

## 如果双击没反应，提示「无法打开」

这是 Mac 的安全保护，不是坏了：

1. 不要直接双击，改成**右键点这个文件，选「打开」**
2. 弹窗里再点一次「打开」
3. 以后就能正常双击了

## 切换模式（性价比 / 最高准确）

两个模式想用哪个都可以，随时切换（需要已下载对应的模型）：

- 双击 **切换到-性价比.command**：速度快、占用小
- 双击 **切换到-最高准确.command**：更精准，速度会慢一些
